# TypeUp 测试版使用说明

## 1. 安装

双击安装包：

```text
TypeUp-Setup-0.1.10.exe
```

如果你收到的是更高版本的 `TypeUp-Setup-*.exe`，优先安装最新版本。

如果 Windows 提示“未知发布者”或“Windows 已保护你的电脑”，这是因为测试版还没有代码签名证书。可以点“更多信息” -> “仍要运行”。

## 2. 注册账号

打开 TypeUp 后，在左侧模块栏进入“账号”模块并注册账号。

注册时请使用标准邮箱格式，密码至少 8 位。

后端地址默认已经配置好，不需要手动填写：

```text
http://150.158.146.192:6053
```

注册成功后会自动获得免费体验：

```text
语音额度：10 小时
AI 额度：3000 次
有效期：30 天
```

所以测试时不需要先购买订阅。

## 3. 授权权限

首次使用时，如果 Windows 弹出权限或安全提示，请允许：

- 麦克风权限
- 防火墙网络访问
- 输入/快捷键相关提示

如果麦克风没有声音，检查：

```text
Windows 设置 -> 隐私和安全性 -> 麦克风
```

确认 TypeUp 或桌面应用可以使用麦克风。

## 4. 开始使用

打开 TypeUp 后点击“启动”。

默认 Windows 快捷键：

```text
按住 ALT：说话转文字
松开 ALT：自动输入到当前光标位置
按住 ALT + SPACE：AI 编辑/修改
双击 ALT：切换原生/微润色模式
```

如果要测试 AI 编辑，建议先在输入框里选中一段文字，再按住 `ALT + SPACE` 说“把这段改正式一点”或“翻译成英文”。正常情况下，说话期间选中的文字应保持在原处，AI 处理完成后才会一次性替换。

使用前先把光标点到要输入文字的地方，比如：

- 记事本
- 微信输入框
- 浏览器输入框
- Word

然后按住 `ALT` 说话，松开后等待几秒，文字会自动输入进去。

## 5. 建议测试内容

请重点测试这些场景：

1. 是否能正常注册和登录。
2. 注册后是否显示“服务已开通”或权益 active。
3. 按住 `ALT` 说话后，是否能转写并输入文字。
4. 在微信、浏览器、记事本里是否都能输入。
5. `ALT + SPACE` 做 AI 编辑时是否能听清并改写，选中文本是否只在结果完成后被替换。
6. 软件是否会提示麦克风、网络、STT 配置错误。
7. 桌面状态框是否稳定，有没有闪烁、卡住或一直显示处理中。

## 6. 常见问题

### 提示“请检查网络或 STT 配置”

先确认电脑能上网，然后在 TypeUp 里退出登录并重新登录一次，再点“重启”。

### 说完后一直显示“处理中”

先等 5-10 秒。如果一直不恢复，点 TypeUp 里的“重启”。

### 按快捷键没反应

确认 TypeUp 已经点了“启动”，并且当前输入框已经获得光标焦点。

### 安装包被拦截

测试版暂时没有代码签名，部分杀毒软件或 Windows SmartScreen 会提醒。这个不代表软件一定有问题，正式发布前会考虑代码签名。

## 7. 反馈时请带上

反馈问题时，请尽量说明：

- 使用的 Windows 版本
- 在哪个软件里测试，例如微信/浏览器/Word
- 当时按了哪个快捷键
- TypeUp 界面显示的状态
- 是否有报错文字
- 问题能否稳定复现
